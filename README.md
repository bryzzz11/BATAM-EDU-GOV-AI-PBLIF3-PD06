# BATAM-EDU-GOV-AI-PBLIF3-PD06
BATAM EDU-GOV AI adalah platform e-Government yang mengintegrasikan bantuan pendidikan tinggi Pemkot Batam. Dengan OCR dan Explainable AI, sistem memeriksa dokumen, mencocokkan data, mendeteksi duplikasi, serta memberi rekomendasi kelayakan administratif. Keputusan akhir tetap dilakukan pemerintah melalui prinsip human-in-the-loop.
